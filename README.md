# 🚗 Garage System Analysis

## 📌 Project Overview

Garage System Analysis is a database management project designed to manage and analyze the operations of a vehicle service garage. The system stores information related to customers, vendors, employees, spare parts, purchases, and service transactions using SQL tables and queries.

## 🎯 Objectives

* Manage customer and vehicle service records.
* Track spare parts inventory and purchases.
* Maintain employee and vendor information.
* Analyze garage operations using SQL queries.
* Generate reports for business decision-making.

## 🛠️ Technologies Used

* SQL
* Oracle Database
* Database Design
* Relational Database Management System (RDBMS)

## 📂 Database Modules

### Customer Management

* Customer details
* Contact information
* Credit days tracking
* Registration records

### Vendor Management

* Vendor details
* Supplier information
* Credit period management

### Employee Management

* Employee records
* Job roles
* Salary information
* Joining and leaving dates

### Spare Parts Management

* Spare parts inventory
* Unit and pricing details
* Stock monitoring

### Purchase Management

* Spare parts purchases
* Vendor transactions
* GST and transportation cost tracking

## 🚀 Features

* Customer record management
* Employee information management
* Vendor and supplier tracking
* Spare parts inventory control
* Purchase transaction analysis
* SQL-based reporting and data retrieval
* Relational database design with primary and foreign keys

## 📊 Learning Outcomes

* Database normalization concepts
* SQL query writing and optimization
* Primary and foreign key implementation
* Data analysis using relational databases
* Real-world garage management system design
